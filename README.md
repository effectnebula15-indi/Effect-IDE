# Effect IDE

Кроссплатформенная IDE с локальным исполнением кода пользователя, включая графику.
Приоритет платформ: **Android → Desktop** (Linux, Windows, macOS). iOS и web не поддерживаются
и не учитываются в архитектурных решениях.

Состояние: **начало разработки**. Собирается ядро, десктопная заглушка и Android-прототип,
в котором Python исполняется в отдельном процессе. Редактора пока нет — см.
[дорожную карту](docs/plan.md).

## Что это будет

- Собственное ядро редактора (не обёртка над системным полем ввода): rope, виртуализация
  отрисовки, tree-sitter, LSP, множественные курсоры.
- Исполнение кода пользователя **локально на устройстве**, в отдельном процессе:
  Python через встроенный CPython, позже — WASM и удалённый бэкенд на своём ПК.
- Графический вывод: программа рисует через собственный Canvas API, IDE показывает кадры
  в `SurfaceView` на Android и в Skia на десктопе.

## Чего здесь не будет (осознанные антицели v1)

Маркетплейс плагинов, совместная работа в реальном времени, десятки языков, встроенный
ИИ-ассистент, эмуляция Linux-окружения, сборка Android-приложений внутри IDE.

## Сборка

Нужен JDK 21 и Android SDK (платформа 37.2, build-tools 36, NDK 29.0.14206865).
Путь к SDK — в `local.properties`: `sdk.dir=/путь/к/android-sdk`.

```bash
./gradlew build                    # сборка, тесты, lint
./gradlew checkArchitecture        # проверка границ между модулями
./gradlew :app:desktop:run         # десктопная заглушка
./gradlew :app:android:assembleDebug   # APK прототипа
```

При первой сборке Android-части качается официальная сборка CPython с python.org
(22 МБ) и сверяется по sha256.
