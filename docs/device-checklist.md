# Что проверяется только на телефоне

Эмулятора нет ни в CI, ни в агентских сессиях: `/dev/kvm` недоступен. Всё, что ниже,
может проверить только человек с устройством, и до этой проверки оно считается
непроверенным — не «наверное работает».

Список — оглавление, а не копия: подробности и таблицы ожиданий живут рядом с кодом,
здесь только порядок и ссылки.

## Как поставить

APK собирается в CI и лежит в артефактах сборки (`effect-ide-debug-apk`). Локально:

```bash
./gradlew :app:android:assembleDebug
adb install -r app/android/build/outputs/apk/debug/app-android-debug.apk
adb logcat -s eide.runner eide.canvas   # смотреть при разборе неудач
```

## Чего в списке нет и не будет

- **Барьеры памяти.** Санитайзеры на x86 их не проверяют в принципе: снятый барьер
  проходит мимо тестов. Это видно только на ARM, то есть на телефоне, и то не всегда.
- **Холодный старт и RSS.** Меряются на устройстве, и желательно на слабом:
  флагман скроет нарушение целей (≤ 1.5 с, ≤ 250 МБ).
- **Панель git.** На телефоне её нет: репозиторию неоткуда взяться, клонирования нет.

## Что делать с результатом

Расхождение с ожиданием — это не «баг в телефоне»: в каждом чек-листе третья колонка
говорит, куда смотреть. Достаточно номера пункта и того, что вышло вместо ожидаемого.
