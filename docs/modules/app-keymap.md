# Раскладка клавиш на десктопе

`app/desktop/.../Keymap.kt`, тест — `app/desktop/src/test/.../KeymapTest.kt`.

## Зачем отдельная таблица

Палитра команд показывает рядом с командой её сочетание. В первой редакции
подписи были строками прямо в списке команд: «Ctrl+S» стояло рядом с «Сохранить
всё», а нажатие Ctrl+S не было связано ни с чем. Подпись врала, и заметить это
можно было только попробовав — тесты палитры проверяли, что подпись показана, а
не что она чему-то соответствует.

Теперь список команд и обработчик нажатий строятся из одной таблицы `Binding`:
подпись берётся из `Shortcut`, разбор нажатия — из того же `Shortcut`. Разойтись
им негде по устройству, а не по дисциплине.

## Что связано

| Сочетание | Команда | Откуда взялось |
|---|---|---|
| Ctrl+S | Сохранить всё | IntelliJ |
| Ctrl+F | Найти в файле | IntelliJ |
| Ctrl+Shift+F | Найти в проекте | IntelliJ (Find in Path) |
| Shift+F10 | Запустить | IntelliJ |
| Ctrl+F2 | Остановить | IntelliJ |
| Ctrl+Shift+A | Палитра команд | IntelliJ (Find Action) |
| Ctrl+Shift+P | Палитра команд | VS Code; по привычке набирают чаще |

Запуск и остановка — одна команда с двумя сочетаниями: подпись меняется вместе с
заголовком, чтобы не предлагать остановить то, что не идёт.

Ctrl — он же Cmd на macOS. Различать их в таблице незачем: это одна и та же
клавиша «сделай главное действие», просто под разными пальцами.

## Пока палитра открыта, раскладка молчит

Иначе Enter в палитре запускал бы программу, а стрелки водили бы курсор в тексте
вместо списка. Исключение — само сочетание палитры: оно её и закрывает.

## Что проверяет тест, а что — нет

Тест проверяет **свойства таблицы**: что два сочетания не совпадают (иначе второе
недостижимо — `commandFor` берёт первое) и что подпись называет ровно те
модификаторы, которых сочетание требует.

Чего тест не проверяет: доходит ли нажатие до обработчика. `KeyEvent` в Compose
заворачивает событие AWT, и собрать его в обычном JVM-тесте — значит собрать
половину оконной системы. Вместо этого у самоснимка есть `-Deide.press`:

```bash
./gradlew :app:desktop:run -Deide.press=ctrl+shift+a -Deide.screenshot=/tmp/p.png
./gradlew :app:desktop:run -Deide.press=ctrl+f -Deide.screenshot=/tmp/f.png
```

Разбирает он подпись, а не коды клавиш: строка в командной строке совпадает с
тем, что написано в палитре, и проверяется ровно обещанное. Оба сочетания так и
проверены — палитра открылась, строка поиска открылась.

## Чего нет

- Раскладки на Android: там нет ни Ctrl, ни привычки к нему, а внешняя клавиатура
  — отдельная работа этапа 4.
- Настройки сочетаний. Таблица в коде; переносить её в настройки имеет смысл
  вместе с самими настройками, которых пока нет.
- Сочетаний для свёртки, вкладок и навигации: команд для них в палитре тоже нет.
